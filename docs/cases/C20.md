# C20: Dashboard shows heart rate 0 after update

**Family:** Ward 4: Network  
**Severity:** High

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- The old file has `bpm`. The new code expects `heartRate`.
- `try?` hides the decode error. The code returns 0 silently. The cache has no schema version.

### How to prove it

- Breakpoint: `vitals` is nil. Replace `try?` with `try` and print the error: keyNotFound(heartRate).
- The file content is `{"bpm":72}`.

### Fix

```swift
static func loadHeartRate() -> Int {
    guard let data = try? Data(contentsOf: url) else { return 0 }
    do {
        return try JSONDecoder().decode(VitalsV2.self, from: data).heartRate
    } catch {
        Log.error(.data, "vitals_cache_decode_failed", ["error": "\(error)"])
        try? FileManager.default.removeItem(at: url)   // drop the old-format file
        return 0
    }
}
// Better: store a schemaVersion in the file name or content.
```

### Prevent it next time

- Never swallow errors with `try?` without a log.
- Version your cache.

### One-line summary

Silent wrong data: try? hid a decode error from an old cache file. I logged the error, dropped old files, and versioned the cache.

</details>
