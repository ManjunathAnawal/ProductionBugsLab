# C28: Accessibility audit fails

**Family:** Ward 8: Accessibility and language  
**Severity:** Medium

## Field report

> A hospital accessibility audit failed on the dose card.

## 1. Reproduce

Pick the biggest text size. Run Xcode > Open Developer Tool > Accessibility Inspector > Audit on the Simulator. Turn on VoiceOver.

## 2. Tools to try

- Accessibility Inspector > Audit
- VoiceOver
- Dynamic Type size picker in the case

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- Two buttons have no label (VoiceOver says only 'button').
- The text has a fixed height, so it is clipped at big sizes.
- Status is shown only by a red dot.
- Touch targets are 28 pt (minimum is 44).

### How to prove it

- Audit lists: element has no description, hit area too small, text clipped.

### Fix

```swift
Button {
    decreaseDose()
} label: {
    Image(systemName: "minus.circle")
        .frame(minWidth: 44, minHeight: 44)
}
.accessibilityLabel("Decrease dose")

Text("Give 5000 units every 8 hours.")
    .fixedSize(horizontal: false, vertical: true)   // no fixed height

Label("Needs review", systemImage: "exclamationmark.circle")   // icon + text, not color only
```

### Prevent it next time

- Run the Audit in review.
- Test with the biggest text and VoiceOver.

### One-line summary

Label, Order, Text size, Size of touch, Motion. I fixed labels, removed fixed heights, added text with the color, and made targets 44 pt.

</details>
