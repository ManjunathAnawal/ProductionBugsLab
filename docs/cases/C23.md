## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- First point is an old saved fix (age 3600 s) from New York. One point has accuracy 800 m. One has accuracy -1 (invalid).
- All are used in the sum.

### How to prove it

- Print fixes: the first jump is about 13,000 km.

### Fix

```swift
func isUsable(_ fix: GpsFix) -> Bool {
    return fix.accuracy >= 0              // negative means invalid
        && fix.accuracy < 100             // not too weak
        && fix.ageSeconds < 10            // not an old saved fix
}

let good = fixes.filter(isUsable)
```

### Prevent it next time

- Filter by accuracy and age.
- Reject impossible speeds.
- Test on a real phone outdoors.

### One-line summary

Fresh, Accurate, Frugal. I filtered stale, weak and invalid fixes before adding distances.

</details>
