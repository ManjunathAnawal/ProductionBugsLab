# C33: Battery drain and a warm phone

**Family:** Ward 9: Release and tools (real phone)  
**Severity:** High

## Field report

> After using fall detection the battery drains fast and the phone gets warm.

## 1. Reproduce

Tap Start fall-detection sensor. Leave the screen. Watch the CPU and Disk gauges in Xcode for one minute.

## 2. Tools to try

- Xcode CPU, Disk and Energy gauges
- Instruments: Time Profiler, File Activity, Energy Log
- Console

## 3. Where the bug lives

- `TriageLab/Logic/L33_SensorPoller.swift`

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- A timer runs every 10 ms (100 times a second). Each tick opens a file and writes one line.
- Nothing stops it when you leave the screen.

### How to prove it

- Time Profiler: `poll()` and file I/O. File Activity: constant writes. CPU never drops.

### Fix

```swift
func start() {
    // 10 times a second is enough, and batch the writes.
    timer = Timer.scheduledTimer(withTimeInterval: 0.1, repeats: true) { [weak self] _ in
        self?.collect()
    }
}

func stop() {
    timer?.invalidate()
    timer = nil
    flushBufferToDisk()
}
// Write in batches. Call stop() when the feature is not needed.
```

### Prevent it next time

- Lowest rate that works.
- Batch disk writes.
- Stop work when the screen is gone.

### One-line summary

Battery drain: a 100 Hz timer writing to disk and never stopping. I lowered the rate, batched writes, and stopped it when not needed.

</details>
