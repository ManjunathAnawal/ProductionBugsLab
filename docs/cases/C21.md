# C21: Nurse note vanishes after app ends

**Family:** Ward 5: Data, time, location  
**Severity:** High

## Field report

> A nurse's note disappeared after the app ended during a save.

## 1. Reproduce

Type a note. Tap Save note, mid-write end. Run again. Tap Load note.

## 2. Tools to try

- Console (note_save_start without note_save_end)
- Devices and Simulators > Download Container
- Breakpoint in load()

## 3. Where the bug lives

- `TriageLab/Logic/L21_NotesStore.swift`

> Tip: do not open these files yet. Reproduce and investigate first.

## Hints (one at a time)

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- The file is written in a way that is not atomic. The app ended after half the data was on disk.
- Half a JSON file cannot be decoded. `load()` returns nil, so the note looks lost.

### How to prove it

- Log: `note_save_start` with no `note_save_end`.
- note.json in the container is cut in the middle.

### Fix

```swift
let data = try JSONEncoder().encode(note)
try data.write(to: url, options: [.atomic])     // all or nothing
// Keep the last good file as a backup and log decode errors on load.
```

### Prevent it next time

- Write atomically.
- Log load failures.
- Test by ending the app during save.

### One-line summary

Half-written file after the app ended. Atomic writes make it all or nothing. I also keep a backup and log load errors.

</details>
