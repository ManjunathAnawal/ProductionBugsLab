# C15: List stutters while scrolling

**Family:** Ward 3: Hangs, launch, speed  
**Severity:** Medium

## Field report

> The vitals list stutters when scrolling fast.

## 1. Reproduce

Scroll the list quickly up and down.

## 2. Tools to try

- Xcode CPU gauge
- Instruments: Time Profiler / Animation Hitches

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- `RowCost.label` runs a 200,000-step loop for every row, on the main thread, inside `body`.

### How to prove it

- Time Profiler: `RowCost.label` dominates the main thread while scrolling.

### Fix

```swift
// Compute once, off the main thread, and keep body cheap.
@State private var labels: [Int: String] = [:]

.task {
    labels = await Task.detached {
        Dictionary(uniqueKeysWithValues: (0..<300).map { ($0, RowCost.label($0)) })
    }.value
}
```

### Prevent it next time

- `body` must be cheap.
- Profile scrolling on the oldest phone.

### One-line summary

Hitches came from heavy work inside body for each row. Time Profiler showed it. I precomputed off main.

</details>
