# C24: Balance went negative

**Family:** Ward 6: Threads and queues  
**Severity:** High

## Field report

> After two quick purchases the balance is negative.

## 1. Reproduce

Tap Buy two tests at once.

## 2. Tools to try

- Breakpoint inside buy()
- Console (wallet_lab)
- Reading: where is the await?

## 3. Where the bug lives

- `TriageLab/Logic/L24_Wallet.swift`

> Tip: do not open these files yet. Reproduce and investigate first.

## Hints (one at a time)

<details><summary>Hint 1</summary>

Both purchases returned true. Why?

</details>

<details><summary>Hint 2</summary>

Look for an `await` between the check and the change.

</details>

<details><summary>Hint 3</summary>

Actors are reentrant at every await.

</details>

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- The balance is checked, then the code awaits, then it subtracts.
- While the first call waits, the second one enters the actor and passes the same check.

### How to prove it

- Result: [true, true], balance -60.

### Fix

```swift
func buy(price: Int) async -> Bool {
    guard balance >= price else { return false }
    balance -= price                                 // reserve FIRST
    let ok = await charge(price)                     // the await is a door
    if !ok {
        balance += price                             // undo
    }
    return ok
}
```

### Prevent it next time

- After every `await`, check state again.
- Change state before awaiting.

### One-line summary

Actor reentrancy: state changed across an await. I reserved the money first and undid it on failure.

</details>
