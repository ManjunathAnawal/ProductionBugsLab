# C26: Band found but never connects

**Family:** Ward 7: Bluetooth (fake band)  
**Severity:** High

## Field report

> The heart band is found but never connects. No error is shown.

## 1. Reproduce

Tap Connect to heart band. Wait 10 seconds.

## 2. Tools to try

- Console filter: ble
- Breakpoint in didConnect (never hit)
- Debug Memory Graph (is the peripheral alive?)

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- The client calls connect(peripheral) but stores the peripheral nowhere. The central holds it weakly, so it is freed.
- The connection is dropped silently. There is no timeout, so the screen waits forever.

### How to prove it

- Log: `ble_connect_start`, then nothing. No `ble_connected`.
- Breakpoint in `central(didConnect:)` is never reached.

### Fix

```swift
private var band: FakePeripheral?                    // strong reference

func central(didDiscover peripheral: FakePeripheral) {
    band = peripheral
    central.connect(peripheral)
    DispatchQueue.main.asyncAfter(deadline: .now() + 10) { [weak self] in
        guard let self, self.band?.isConnected != true else { return }
        self.onStatus?("Could not connect. Try again.")     // own timeout
    }
}
```

### Prevent it next time

- Keep the peripheral in a strong property.
- Add your own connect timeout.

### One-line summary

Connect never finished: the peripheral was not retained and connect has no timeout. I stored it and added my own timer.

</details>
