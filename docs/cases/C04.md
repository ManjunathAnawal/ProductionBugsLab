## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- Patient 3 has no `doctor`. The model says `doctor` is optional, which is correct.
- The code does `record.doctor!.name`. A force unwrap of nil traps.

### How to prove it

- Xcode stops on `record.doctor!.name`. Console says: Unexpectedly found nil while unwrapping an Optional value.
- Print the record: doctor is nil.

### Fix

```swift
func doctorName(forPatient id: Int) -> String {
    guard let record = records.first(where: { $0.id == id }) else {
        return "Unknown patient"
    }
    guard let doctor = record.doctor else {
        Log.error(.data, "doctor_missing", ["patient": String(id)])
        return "Not assigned"
    }
    return doctor.name
}
```

### Prevent it next time

- No `!` on data that comes from outside the app.
- Test with missing, null and extra fields.

### One-line summary

Nil force unwrap. The server left a field out. I used guard-let, logged it, and showed a clear fallback.

</details>
