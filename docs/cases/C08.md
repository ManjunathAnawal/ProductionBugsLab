# C08: Purple warning: publishing from background

**Family:** Ward 2: Crashes  
**Severity:** Low

## Field report

> Developers see a purple warning in Xcode. Sometimes the screen does not update.

## 1. Reproduce

Tap Scan. Open the Issue Navigator (triangle icon) and the console.

## 2. Tools to try

- Xcode Issue Navigator (Runtime Issues)
- Main Thread Checker (Edit Scheme > Run > Diagnostics)
- Console

## 3. Where the bug lives

- `TriageLab/CaseViews/W2_Crashes.swift`

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- `status` is changed inside `DispatchQueue.global().async`. UI state must change on the main thread.

### How to prove it

- Issue Navigator: Publishing changes from background threads is not allowed.
- Turn on Main Thread Checker for stricter reports.

### Fix

```swift
@MainActor
final class ScanViewModel: ObservableObject {
    @Published var status = "idle"

    func scan() {
        status = "scanning"
        Task {
            try? await Task.sleep(nanoseconds: 1_000_000_000)
            status = "done"
        }
    }
}
```

### Prevent it next time

- Mark view models `@MainActor`.
- Keep Main Thread Checker on in debug.

### One-line summary

UI state changed off the main thread. I made the view model @MainActor and used async work.

</details>
