# C19: Users logged out at random

**Family:** Ward 4: Network  
**Severity:** High

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- Five calls get 401 at the same time. Each one refreshes the token on its own.
- The refresh token works once. The first refresh wins. The other four fail and the client logs the user out.

### How to prove it

- Log: five `got_401`, one `refresh_ok`, four `refresh_failed_logged_out`.

### Fix

```swift
actor TokenRefresher {
    private var inFlight: Task<Tokens, Error>?

    func refresh() async throws -> Tokens {
        if let running = inFlight {
            return try await running.value        // join the running refresh
        }
        let task = Task { try await callRefreshEndpoint() }
        inFlight = task
        defer { inFlight = nil }
        return try await task.value
    }
}
```

### Prevent it next time

- Single-flight refresh.
- Log request IDs and timing.

### One-line summary

Many 401s caused many refreshes with a rotating token. I made refresh single-flight with an actor so all callers share one refresh.

</details>
