# C05: Crash on the third page

**Family:** Ward 2: Crashes  
**Severity:** Medium

## Field report

> Crash when a nurse taps Next page for the third time.

## 1. Reproduce

Tap Next page twice.

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- `start..<end` goes past the end of the array on the last page (20..<30 with 25 items).

### How to prove it

- Xcode stops at `Array(readings[start..<end])`. Error: Index out of range.

### Fix

```swift
func page(_ number: Int) -> [String] {
    let start = number * pageSize
    guard start < readings.count else { return [] }
    let end = min(start + pageSize, readings.count)
    return Array(readings[start..<end])
}
```

### Prevent it next time

- Unit test the last page and an empty page.
- Never trust a computed index.

### One-line summary

Off-by-one at the last page. I clamped the end index and added a unit test for the edge.

</details>
