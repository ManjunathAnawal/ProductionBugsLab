## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- Each phone retries 10 times immediately for any failure. No wait, no randomness, no stop for hopeless errors.

### How to prove it

- Result: 100 phones send 1000 requests. Log line `retry_lab` shows the same.

### Fix

```swift
static func fetchWithRetry(server: OutageServer) async {
    for attempt in 1...3 {                                  // small cap
        if server.call() == 200 { return }
        let ceiling = min(4.0, 0.5 * pow(2.0, Double(attempt - 1)))
        let wait = Double.random(in: 0...ceiling)           // backoff + jitter
        try? await Task.sleep(nanoseconds: UInt64(wait * 1_000_000_000))
    }
}
// Retry only timeouts and 5xx. Never retry 4xx. Keep a remote kill switch.
```

### Prevent it next time

- Backoff with jitter. Max attempts.
- A flag to turn retries off.

### One-line summary

A retry storm. I capped attempts, added exponential backoff with jitter, retried only transient errors, and kept a kill switch.
