# C25: Uploads stop at scan 3

**Family:** Ward 6: Threads and queues  
**Severity:** High

## Field report

> Uploads stop at scan 3. Scans 4 and 5 never upload.

## 1. Reproduce

Tap Upload 5 scans. Wait 10 seconds.

## 2. Tools to try

- Xcode Pause + Debug Navigator
- Console (upload_failed, upload_ok)
- Breakpoint in UploadOperation.main

## 3. Where the bug lives

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- The queue runs one operation at a time. An async operation must call `finish()` on every path.
- Scan 3 fails and returns without `finish()`. The queue waits forever.

### How to prove it

- Log: upload_ok 1, upload_ok 2, upload_failed 3, then nothing.
- Debugger: operation 3 `isFinished` is false.

### Fix

```swift
DispatchQueue.global().asyncAfter(deadline: .now() + 0.4) {
    defer {
        self.finish()                 // runs on EVERY path
    }
    if self.index == 3 {
        self.onResult(self.index, false)
        return
    }
    self.onResult(self.index, true)
}
```

### Prevent it next time

- LOCF: Limit, Order, Cancel, Finish.
- Use `defer { finish() }`.

### One-line summary

A serial queue stalls if one async operation never finishes. I used defer so finish runs on every path.

</details>
