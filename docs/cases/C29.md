# C29: Wrong arrows and raw keys in Arabic

**Family:** Ward 8: Accessibility and language  
**Severity:** Low

## Field report

> Arabic and Hebrew testers say arrows point the wrong way and some text looks like a code.

## 1. Reproduce

Switch on Right-to-left layout. Set Readings to 1.

## 2. Tools to try

- Edit Scheme > Run > Options > App Language: Right to Left Pseudolanguage and Double-Length Pseudolanguage
- Xcode Previews

## 3. Where the bug lives

- `TriageLab/CaseViews/W8_UI.swift`

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- `chevron.left` is hard-coded and does not flip.
- `vitals.title` has no entry in a strings file, so the key shows.
- '1 readings' has no plural rule.
- The date format is fixed to US style.

### How to prove it

- In right-to-left mode the arrow still points left. The key text appears on screen.

### Fix

```swift
Image(systemName: "chevron.backward")                 // flips with the language

Text("vitals.title")                                   // add this key to Localizable.xcstrings
Text("readings_today \(count)")                        // plural variations in the String Catalog

Text(Date(), format: .dateTime.day().month().year())   // follows the user's region
```

### Prevent it next time

- Use leading and trailing, never left and right.
- String Catalog with plurals.
- Test with pseudolanguages.

### One-line summary

I tested with the right-to-left and double-length pseudolanguages. I used backward chevrons, string catalog plurals, and locale-aware dates.

</details>
