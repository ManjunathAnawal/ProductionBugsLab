# C31: Silent kill on an iPhone 11

**Family:** Ward 9: Release and tools (real phone)  
**Severity:** Critical

## Field report

> Nurses say the app closes while scanning on an iPhone 11. The crash dashboard is empty.

## 1. Reproduce

Use a real iPhone. Tap Allocate 50 MB again and again. Watch Memory left fall. iOS closes the app.Reopen the app. Open Black Box.

## 2. Tools to try

- Black Box: last-run report
- Console (silent_end_suspected)
- Xcode Organizer > Terminations
- Debug > Simulate MetricKit Payloads

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- The app grew until iOS closed it (memory limit). iOS gives no crash report for that.

### How to prove it

- Black Box: `unknown_in_foreground`, last screen C31, last memory left close to 0.
- Log: `silent_end_suspected`.

### Fix

```swift
// Detection (already in this app):
// 1. save heartbeat values every few seconds
// 2. on next launch compare: clean exit? updated? reboot? background?
// 3. otherwise: unknown_in_foreground  = hidden crash

// Fix the cause: use less memory (thumbnails, caches with limits).
```

### Prevent it next time

- Count `unknown_in_foreground` per version.
- Watch Organizer Terminations.

### One-line summary

No crash report means iOS closed it. My last-run log showed a foreground end with almost no memory left, which proved a memory kill.

</details>
