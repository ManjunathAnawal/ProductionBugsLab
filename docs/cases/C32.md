# C32: Nightly sync is 'scheduled' but never runs

**Family:** Ward 9: Release and tools (real phone)  
**Severity:** Medium

## Field report

> The log says the nightly sync was scheduled. It never runs.

## 1. Reproduce

Use a real iPhone. Tap Schedule nightly sync. Read the log. Then find out why nothing runs.

## 2. Tools to try

- Console
- Info.plist (BGTaskSchedulerPermittedIdentifiers)
- Breakpoint on the submit line
- Debug: simulate a background task launch

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- The code uses `.nightly`. Info.plist allows `.nightly-sync`. The system refuses the request.
- `try?` hides the error, so the log still says 'scheduled'.

### How to prove it

- Replace `try?` with `do/catch`: error BGTaskSchedulerErrorDomain, not permitted. (On the Simulator the error is 'unavailable'. Background tasks are not supported there.)

### Fix

```swift
do {
    try BGTaskScheduler.shared.submit(request)
    Log.info(.background, "nightly_sync_scheduled")
} catch {
    Log.error(.background, "nightly_sync_schedule_failed", ["error": "\(error)"])
}
// Make the identifier in code match Info.plist exactly.
```

### Prevent it next time

- Never hide scheduling errors.
- Log scheduled, started, time-up, finished.
- Always add catch-up sync on app open.

### One-line summary

try? hid a notPermitted error. The identifier in code did not match Info.plist. I logged the error and fixed the identifier.

</details>
