# C13: Freeze for a few seconds, CPU high

**Family:** Ward 3: Hangs, launch, speed  
**Severity:** Medium

## Field report

> The app freezes for several seconds when building the summary. The phone gets warm.

## 1. Reproduce

Tap Build daily summary. Try to scroll or tap during the freeze.

## 2. Tools to try

- Xcode CPU gauge
- Instruments: Time Profiler
- Console (main_thread_hang)

## 3. Where the bug lives

- `TriageLab/Logic/L13_Sorter.swift`

> Tip: do not open these files yet. Reproduce and investigate first.

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- Eight sorts of 1,000,000 numbers run on the main thread. The main thread is busy, not waiting.

### How to prove it

- Time Profiler: `ReadingSorter.buildSummary` and `sort` at the top. Main thread 100% busy.
- Hang detector logs main_thread_hang.

### Fix

```swift
Button("Build daily summary") {
    isWorking = true
    Task.detached {
        let total = ReadingSorter.buildSummary()
        await MainActor.run {
            message = "Summary ready: \(total)"
            isWorking = false
        }
    }
}
```

### Prevent it next time

- Heavy work goes off the main thread, with a spinner.
- Profile with Time Profiler before release.

### One-line summary

High CPU: the main thread was busy. Time Profiler showed the sort at the top. I moved it off main.

</details>
