# C12: App freezes forever

**Family:** Ward 3: Hangs, launch, speed  
**Severity:** Critical

## Field report

> The app freezes completely when building the daily report. No crash.

## 1. Reproduce

Tap Build report. The app freezes. In Xcode use Debug > Pause (or the pause button).

## 2. Tools to try

- Xcode Pause + Debug Navigator main thread stack
- Console (main_thread_hang)
- Instruments: Hangs

## 3. Where the bug lives

- `TriageLab/Logic/L12_ReportBuilder.swift`

> Tip: do not open these files yet. Reproduce and investigate first.

## Hints (one at a time)

<details><summary>Hint 1</summary>

Pause the app and read what the main thread is doing.

</details>

<details><summary>Hint 2</summary>

Is the CPU high or low? A frozen app with low CPU is waiting.

</details>

<details><summary>Hint 3</summary>

The main thread waits for a result. The worker needs the main thread to deliver it.

</details>

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- `buildReport()` runs on the main thread and calls `semaphore.wait()`.
- The worker thread sends the result with `DispatchQueue.main.async`. The main thread is blocked, so that block never runs. Deadlock.

### How to prove it

- Pause: main thread is in `semaphore_wait_trap`. CPU is near 0%.
- Console: `main_thread_hang` from the live hang detector.

### Fix

```swift
func buildReport(completion: @escaping (String) -> Void) {
    DispatchQueue.global().async {
        let text = self.collectNumbers()
        DispatchQueue.main.async {
            completion(text)
        }
    }
}
// The caller shows a spinner and updates when the completion runs.
```

### Prevent it next time

- Never wait for another thread on the main thread.
- Main Thread Checker and a hang detector in debug.

### One-line summary

Low CPU freeze means waiting, not working. I paused the app and saw the main thread blocked on a semaphore while the worker needed main.

</details>
