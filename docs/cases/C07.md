# C07: Crash when syncing in a lift

**Family:** Ward 2: Crashes  
**Severity:** High

## Field report

> Nurses report a crash when syncing favorites in lifts and tunnels.

## 1. Reproduce

Turn on Poor network. Tap Sync favorites. Wait 3 seconds.

## Answer

<details><summary>Show the answer (try first!)</summary>

### Root cause

- The code waits at most 3 seconds, then calls `fatalError`.
- A slow network is normal. The timeout is not a bug.

### How to prove it

- Crash is on a background thread. Message: Sync took too long.
- Log shows `sync_start` with network_delay_s=5 and no `sync_ok`.

### Fix

```swift
func syncFavorites(simulatedNetworkDelay: Double, completion: @escaping (Bool) -> Void) {
    // Never wait on a thread. Use a completion and a longer timeout.
    DispatchQueue.global().asyncAfter(deadline: .now() + simulatedNetworkDelay) {
        completion(true)
    }
}
// On timeout: call completion(false) and show 'Will retry later'.
```

### Prevent it next time

- `fatalError` is for bugs, not for slow networks.
- Test with Network Link Conditioner.

### One-line summary

A timeout turned into fatalError. I handled the timeout, gave slow networks more time, and showed a retry message.

</details>
